# 🔮 Tarot App

A simple and elegant Tarot card drawing app built with Flutter.

## ✨ Features

- 🎴 Random tarot card drawing

- 📖 Card meaning interpretation
- 🎨 Clean and minimal UI design
- 📱 Android emulator support
